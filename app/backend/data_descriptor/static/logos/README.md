# Third-party logos

The home page shows these logos in white, on its workflow tiles and in its navigation bar, to name the technology each
workflow works with. Small print on each tile says whose technology it is and that Flyover is not affiliated with them.
Neither W3C nor OHDSI endorses Flyover, sponsors it or is affiliated with it.

## `w3c-semantic-web-cube.svg`: W3C's Semantic Web cube, for RDF

- Owner: W3C (World Wide Web Consortium). The cube stands for the Semantic Web technologies, RDF among them.
- Source: <https://www.w3.org/Icons/SW/sw-cube-v.svg>, listed on <https://www.w3.org/2007/10/sw-logos.html> as the
  "Semantic Web Cube alone (no W3C logo)" (retrieved 2026-11-09).
- Terms (from that page): use is governed by the W3C Document License, except that the logo's size and colours may be
  changed without permission. On the Web, attribution is required by one of these means: the image's alt text is
  "W3C Semantic Web Logo"; the SVG keeps W3C's original metadata; or the logo links to <http://www.w3.org/2001/sw/>.
  Flyover does the first two: the tile's image has that alt text, and the file keeps its metadata. The navigation bar
  shows the same file beside the word RDF, with an empty alt text so screen readers read the name once.
- Flyover shows it turned white by CSS (`filter`), as W3C allows for the cube without the W3C mark ("May I change the
  cube colors? If there is a "W3C" in the logo, no. Otherwise, yes.").
- W3C's other marks did not fit the tile's circle: its RDF technology button is a wide "W3C | RDF" strip, and the
  classic RDF graph icon was deprecated in 2007.
- Stored as published, except that Git turns its Windows line endings into Unix ones; the drawing is the same.
- Keep its proportions. Check the source now and then for updates, as W3C asks for local copies.

## `ohdsi-logo-only-white.png`: the OHDSI logo, in white

- Owner: OHDSI (Observational Health Data Sciences and Informatics), which maintains the OMOP Common Data Model.
- Source: OHDSI's own white version, `OHDSI/OHDSI logo only - white.png` in <https://github.com/OHDSI/VisualIdentity>
  (retrieved 2026-11-09). Using a version OHDSI publishes keeps its design and colours intact: Flyover does not
  recolour, fade or crop it.
- Terms: the repository's "Policy Statement on the Use of Visual Identity for OHDSI" (effective 9 June 2023). It allows
  use for OHDSI-related activities, including digital media and related academic or research endeavours, as long as the
  design, colours and proportions stay intact and the use does not imply endorsement, sponsorship or affiliation with a
  product OHDSI has not recognised or approved. The policy names no licence, and the OHDSI Coordinating Center
  (contact@ohdsi.org) may review its use and change the policy without notice.
- The OMOP tile therefore says, beside the logo, that the OMOP CDM is maintained by OHDSI and that Flyover is not
  affiliated with OHDSI.
